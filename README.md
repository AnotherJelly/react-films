# react-films
github pages link: https://anotherjelly.github.io/react-films/

### 1. Клонируйте репозиторий

```bash
git clone https://github.com/AnotherJelly/react-films
cd react-films
```

### 2. Установите зависимости

```bash
npm install
```

### 3. Запустите приложение в режиме разработки

```bash
npm run dev
```

Приложение будет доступно по адресу: http://localhost:5173/react-films/ (если порт доступен)
